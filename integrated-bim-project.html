01 / PROJECT OVERVIEW

Interoperability & Design Coordination with BIM

This academic group project explored how building information models can be shared, checked and used across different software platforms to support design coordination and construction planning.

The workflow used a residential building model developed in ArchiCAD, with BIMcloud supporting collaborative working. IFC exchanges were examined by comparing the native model with imported versions, followed by model checking in Solibri using architectural and structural models. The workflow then continued into SYNCHRO, where model elements were associated with schedule tasks to develop a 4D construction sequence.

The project examined both the benefits and limitations of information exchange, including changes to geometry and element properties during IFC conversion.

02 / METHODOLOGY

From model authoring to 4D planning

01

Model Authoring & Collaboration

A residential BIM model was developed in ArchiCAD. Teamwork and BIMcloud supported the shared project environment, while project location and coordinate settings established the model's reference information.

ArchiCAD · BIMcloud

02

IFC Interoperability

The native ArchiCAD model was compared with IFC exports and imported models. Different export approaches were examined to understand how geometry, element classification, materials and properties could change during exchange.

ArchiCAD · IFC

03

Model Checking & Issue Reporting

Architectural and structural IFC models were reviewed in Solibri. Rules-based checks were used to identify coordination issues, review clashes and prepare BCF issue information for communication between applications.

Solibri · BCF

04

4D Construction Planning

The IFC model was imported into SYNCHRO. Model elements were selected and associated with schedule tasks to develop a Gantt-based programme and visualise the construction sequence over time.

SYNCHRO 4D

04 / KEY LEARNING

Coordinating information across platforms

The project demonstrated how an interoperable BIM workflow can connect model authoring, design checking and construction sequencing. It also highlighted the need to review IFC exchanges carefully, as geometry and element information may not transfer identically between software applications.
