# Architectural Portfolio Template

A simple static architectural portfolio designed for GitHub Pages.

## Files
- `index.html` — portfolio content
- `style.css` — visual design
- `script.js` — small interaction

## Run locally
Open `index.html` in a browser.

## Publish on GitHub Pages
1. Create a new GitHub repository.
2. Upload these three files.
3. Go to **Settings → Pages**.
4. Under Build and deployment, select **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save.
7. GitHub will provide your live `github.io` address.

## Customise
Replace the example project text and the CSS placeholder image areas with your own project images. Add your CV PDF and update the CV link in `index.html`.
