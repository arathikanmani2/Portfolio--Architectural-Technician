PROJECT

Technical design

Atherton Grove is a development of 13 zero-carbon homes progressing through installation. The project features a brick-slip façade system using Vandersanden products, requiring careful coordination between the supporting structure, external envelope and architectural finishes.

Bespoke elements include chimney assemblies, projecting windows and a volumetric external cladding pod. These interfaces require coordinated detailing of structural connections, waterproofing, façade build-ups and installation requirements.

My role focuses on developing architectural technical details and using Revit models to review interfaces, refine build-ups and resolve potential conflicts. This supports Design for Manufacture and Assembly (DfMA), buildability and accurate on-site installation.
